# wii_onlinable 仕様書

## 1. 概要
`wii_onlinable` は、**「online（オンライン）」** と **「enable（有効化する・可能にする）」** を組み合わせた造語です。Wiiのゲーム環境をネットワーク経由で遠隔操作し、オンラインでのリモートプレイを可能にすることを目的としたシステムです。

---

## 2. システム構成と動作構造
本システムは、ゲーム処理と映像配信を行う**「ホスト側（親機）」**と、実際の操作を行う**「クライアント側（操作・子機）」**の2つの環境を相互に通信させることで構築されます。


```
+-------------------------------------------------------------+
|                      【 wii_onlinable 】                    |
|                                                             |
|   [ホスト側（親機）]                               [操作側（子機）] |
|   ・ゲーム処理                                      ・入力操作の送信  |
|   ・映像・音声の配信   ======(リアルタイム配信)=====>  ・映像の受信・反映|
|   ・操作情報の反映     <=====(操作信号の送信)=======                 |
+-------------------------------------------------------------+
```

### 2.1 ホスト側（提供機器・サーバー）の役割
1. **ベース環境の構築**: 基地となる主の提供機器（ゲーム処理を行うメインサーバー環境）を構築します。
2. **情報の処理と反映**: 遠隔（操作側）から受信した入力情報（キー入力やコントローラー信号）をゲーム内にリアルタイムで反映させ、内部処理を行います。
3. **映像・音声の配信**: 処理されたゲームの映像および音声データを、操作側へリアルタイムでストリーミング配信します。

### 2.2 クライアント側（操作側）の役割
1. **操作情報の送信**: 利用者の入力デバイス（コントローラー等）による操作情報を、ホスト側へ並行してリアルタイム送信します。
2. **映像の受信と反映**: ホスト側から送られてくる映像・音声データを受信し、画面に遅延なく描写・反映させます。

## 3. コンプライアンスおよび著作権に関する重要事項

本システムを利用するにあたり、以下の著作権法および法的事項を**必ず絶対条件として厳守**してください。

* **自己所有データの使用徹底**
  本システムで使用するゲームデータ（ROM、ISO、セーブデータ等）は、**ホストとなるプレイヤー自身が適法に所有しているオリジナルの実機製品から、個人利用の範囲で直接吸い出したデータのみ**としてください。
* **著作権違法行為の禁止**
  インターネット上からダウンロードした海賊版データや、第三者から譲渡・共有された複製物（コピー品）を使用することは、**著作権法違反**となります。違法データを用いたプレイ、および本システムを利用した不特定多数へのゲームデータの共有は絶対に行わないでください。

## 4. システム要件および推奨環境（追記）

快適かつ安全にシステムを運用するため、以下の環境を推奨します。

### 4.1 ネットワーク要件
* **回線速度**: 双方向のデータ転送（映像配信と操作信号の同期）を行うため、ホスト・クライアント共に**高速かつ安定したブロードバンド回線（光回線推奨）**が必要です。
* **接続方式**: 遅延（レイテンシー）やパケットロスを最小限に抑えるため、**有線LAN**での接続を強く推奨します。
* **許容遅延**: 快適なアクション操作を実現するため、Ping値（応答速度）は **20ms以下** を推奨します。
